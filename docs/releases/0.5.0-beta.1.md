# Aura 0.5.0-beta.1

- **Del** samler Azure Static Web Apps, Cloudflare Pages, GitHub Pages, komplai Run, Promte Apps og Vercel i samme forløb. Udbyderne vises alfabetisk med logo, kontokrav og tre valg ad gangen. Ingen udbyder er forvalgt.
- **Promte Apps** guider gennem organisationens adresse, browserlogin, arbejdsområde og valg af kildekode. Aura viser, om versionen bygges, gennemgås, er blokeret eller er udgivet. Knappen **Åbn Promte** fører til arbejdsområdet.
- **GitHub Pages og Cloudflare Pages** får opsætningsfiler i projektet. Aura viser filændringerne først; du gemmer og sender dem med Git. Udgivelsen starter efter dit valg gennem GitHub Actions. Cloudflares adgangstoken gemmes som en hemmelighed hos GitHub.
- **Azure Static Web Apps** guider gennem Microsoft-login, abonnement og valg af en eksisterende app i din egen Azure-opsætning.
- **Vercel** kan følge udgivelser fra et tilsluttet Git-repository og skelne mellem produktion og testversioner. Forbindelsen kan gemmes i projektets opsætning.
- En **fælles status ved Del** følger det åbne projekts udgivelse. Du kan se fremdrift og fejl og åbne appen eller udbyderens arbejdsområde. Gennemgang og kvittering følger samme opbygning på tværs af udbyderne.
- Browserlogin bruges, hvor udbyderen understøtter det. **komplai Run** beholder sit OAuth-login og vises på lige fod med de øvrige muligheder. Promte og komplai kræver konto og betalt aftale.
- **komplai er fjernet som AI-udbyder.** Tidligere gemte AI-forbindelser kan fjernes, men kan ikke længere sende opgaver eller hente modeller. Aura vælger ikke automatisk en anden AI. Run-adgang, projekter, samtaler og kladder bevares.
- Starten af Azure-, SWA-, Vercel- og Promte-værktøjerne er rettet til deres officielle Windows-startfiler. Aura starter Node eller Python direkte, så adresser og filnavne med specialtegn ikke fortolkes som ekstra kommandoer.

## Opdatering

Opdateringsforløbet er uændret. Når automatisk søgning er slået til, søger Aura ved opstart og hver sjette time. Du vælger selv **Hent opdatering** og derefter **Genstart og opdatér**. Igangværende arbejde forhindrer genstart, og kladden gemmes inden installation.

Version 0.3.0-beta.1 og nyere har opdateringsfunktionen under Indstillinger. Ældre versioner kræver en manuel installation af en nyere version.

## Kandidatens afprøvning

De nye udgivelsesforløb er enhedstestet med 74 målrettede tests og afprøvet i Electron med faktiske projektfiler. Appprøverne omfatter 104 skærmbilleder, tastaturbetjening, fejltilstande og visning ved 150 procent zoom. Udbydersvar og login er simuleret i disse prøver; Vercels eksisterende Git-udgivelser og Azure-abonnementer er desuden kontrolleret læsende mod rigtige konti.

Rettelsen til Windows-startfiler er dækket af otte yderligere tests, inklusive faktiske lokale processer med specialtegn og standardinput. En startfil dannet af npm-værktøjet `cmd-shim` 8.0.0 er også afprøvet med direkte Node-start på Mac. Det er ikke en Windows-platformsprøve.

349 relevante enhedsprøver består. Begge Mac-apps er signerede og kontrolleret mod kildekoden. Apple Silicon-appen er desuden afprøvet som pakket app med medfølgende værktøjer og faktiske projektfiler. Windows-installationsfilens indhold og opdateringsmetadata er kontrolleret; den er usigneret.

De endelige DMG- og ZIP-filer til både Apple Silicon og Intel er godkendt af Apple. Slutkontrollen bekræfter signaturer, vedhæftede Apple-billetter, distributionskontrol og match mellem filer og notariseringskvitteringer. Appindholdet i DMG og ZIP er identisk for hver arkitektur og matcher den kontrollerede kildekode.

Native opgradering fra 0.4.0-beta.1 til 0.5.0-beta.1 består med den tidligere pakkes egen opdateringscontroller og Squirrel.Mac: projektfiler, forbindelse, krypteret testnøgle, designpakke og kladde er bevaret uden automatisk modelsendelse. Prøven bruger isolerede brugerdata og kontrolleret manuel genåbning på Apple Silicon; automatisk genstart er ikke afprøvet.

De tre installationsfiler er hentet gennem den lokale downloadside i Chrome; filnavne, størrelser og SHA-256 matcher. Downloadsiden er gennemgået på desktop og mobil. Den samlede hjemmeside og alle tre opdateringsfeeds består lokal kontrol med de faktiske programfiler og simulerede metadata for den kommende udgivelse. Kandidaten er klar til brugerens releasegennemgang, men er endnu ikke offentliggjort.

Windows-installation, fysisk Intel-Mac og de nye eksterne Promte-, GitHub Pages- og Cloudflare Pages-udgivelser er ikke afprøvet. Den aktuelle evidens og afgrænsning står i [teststatus](https://github.com/ai-alliancen-org/ai-harness/blob/main/docs/teststatus.md).

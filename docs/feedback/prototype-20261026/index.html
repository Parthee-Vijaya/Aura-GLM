DIN FØRSTE VERSION

Fra mødeoversigt til tilmelding.

  • Find et møde med dato, sted og ledige pladser.
  • Tilmeld dig og se en tydelig bekræftelse.
  • Se og afmeld dine demotilmeldinger.
  • En rolig, læsbar side på både mobil og computer.

Fiktive møder. Ingen rigtige tilmeldinger eller personoplysninger sendes.

Tekniske valg og afprøvning

Forslaget bruger HTML, CSS og JavaScript. Aura afprøver valg af møde, tomme felter, tilmelding, afmelding og mobilvisning. Andre projekter kan have en anden løsning.

Planvalg og tilladelser er separate. Dette klik kører kun prøvens animation.

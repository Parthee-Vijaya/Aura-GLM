# Tests og evidens

Læs projektets egne test- og byggeinstruktioner før kørsel. Afprøv den ændrede brugerrejse og relevante fejltilfælde. Skeln mellem skrevet, unit-testet, afprøvet med konkret materiale og sat i drift. Påstå aldrig, at en test er kørt, når den ikke er. Følg projektets valgte teststrategi uden at fravælge nødvendige kontroller.

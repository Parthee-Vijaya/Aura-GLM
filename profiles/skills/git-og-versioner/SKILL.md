# Git og versioner

Undersøg projektet og Git-status før ændringer. Bevar brugerens ændringer. Lav aldrig commits, push, grene, merge eller rebase uden en udtrykkelig anmodning om netop handlingen. Afslut en milepæl med oversigt, faktiske testresultater og et dansk commit-forslag. Tilføj ingen modelnavne eller medforfatterskab. En .gitignore fjerner ikke allerede sporede filer.

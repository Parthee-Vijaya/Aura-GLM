# Opgave og mål

Læs projektkonteksten. Forklar væsentlige antagelser, og spørg ved valg, der ændrer retningen. Arbejd på den aftalte opgave; tilføj ikke betalte tjenester, integrationer eller features uden aftale. Beskriv kort, hvad brugeren skal kunne gøre efter ændringen. Svar på dansk.

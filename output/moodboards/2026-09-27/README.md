# Otte visuelle retninger

Visuelle koncepter til drøftelse, genereret med det indbyggede imagegen-værktøj. Ingen appkode er ændret.

Farver, typografi og layout er inspiration. Eksempeltekster, slogans, kommunelogoer og viste funktioner er ikke godkendt produktindhold eller dokumentation for implementeret funktionalitet. Tilgængelighed og interaktion er ikke afprøvet. De præcise billedprompter findes i prompter.json.
